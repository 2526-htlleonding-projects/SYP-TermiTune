== Overview

A terminal-based music player written in Java, capable of managing and playing local MP3/WAV files.
It will have a Spotify Integration for metadata and playback control.

_It combines command-line usability with modern streaming integration_

=== Local Player

* Scan and index local music folders.
* Display metadata (title, artist, album, duration).
* Create, edit, and save playlists (stored in JSON).
* Playback controls like play, pause, skip, ...

== Spotify Integration

* Connect to user’s Spotify account via *Spotify Web API*.
* Display Spotify playlists and saved songs.
* Play Spotify tracks using a *hidden local web service* running Spotify’s Web Playback SDK.
* Unified library view combining local and Spotify tracks.

IMPORTANT: The user will only see the terminal UI, no second web app for spotify.

== Command-Line Interface

* Interactive shell prompt (e.g., mpcli>).
* Commands like play 12, playlist add, spotify connect, search "song name".

== Technical Implementation

* Language: Java
* Audio Engine:
    ** Local: JavaFX MediaPlayer or javazoom.jl (JLayer).
    ** Spotify: Web Playback SDK hosted in local minimal web server.
* Local Web Server: SparkJava or Jetty to bridge terminal ↔ browser player.
* Database: SQLite or flat JSON for playlist and history persistence.

== Optional Extensions
